# My Cold War Mods
A repo of all of my mods in an Open Source fashion.

You are more than welcome to use snippets if it helps you learn how Cold War works.

### AI USAGE
Because most of Cold Wars source scripts were hashed, it was tough to find how some things work, and even though I wanted to avoid AI at all times, ive used it a little bit to figure things out. CODING WISE, almost everything is made by me, I try to use the AI as a tool to point me how Cold War functions.
I do not support vibecoding and if these decompiled scripts were completely readable, I would've avoided using it entirely.
